# RouteSetu Frontend

Responsive React/Vite implementation of the RouteSetu logistics authentication and dispatch dashboard flows.

## Run locally

```bash
npm install
npm run dev
```

Routes:

- `/` Login
- `/signup` Signup
- `/verify-otp` OTP verification
- `/forgot-password` Forgot password
- `/reset-password` Reset password
- `/dashboard` Dispatch dashboard
